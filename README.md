# Superstore Sales Analysis 

A data analytics project focused on uncovering insights from Superstore sales data using tools like **Python**, **Pandas**, **Matplotlib**, and **Seaborn**. The goal is to identify patterns, improve business strategies, and support data-driven decisions.

---

## Project Overview

This project analyzes historical sales data from a retail superstore to:

- Explore key sales and profit trends
- Identify high/low performing categories and sub-categorie
- Analyze product performance
- Discover shipping impacts


---

## 📂 Dataset

- **Source**: [Sample - Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
- **Format**: CSV
- **Size**: ~10,000 records

Key Columns:
- `Order ID`, `Order Date`, `Region`, `Category`, `Sub-Category`, `Sales`, `Profit`, `Quantity`, `Discount`, `Ship Mode`, `Customer Segment`
